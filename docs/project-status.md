## 系统定位与已确认条件

发送端采集一个双轴摇杆、四个按键、两个拨码和 MPU6500 六轴原始数据，在 MCU 上解算姿态，通过透明无线串口发给接收端。两端 SSD1306 分别显示菜单和实时数据；双方 USART2 分别输出诊断文本和 PC 数据。

无线模块按用户说明作为远程串口使用，可按 HC 类透明模块理解。MCU 不处理无线配对或 AT 指令，当前协议采用双向遥测/ACK。IMU 先以传感器 XYZ 为机体坐标，保留可配置映射；本次未新增安装方向或无线往返时间的测量记录，继续沿用用户当前配置。

## 构建证据与边界

当前 CMake Release 链接：发送端 Flash 34,212 B、RAM 7,272 B；接收端 Flash 18,716 B、RAM 5,672 B。RAM 含现链接脚本的堆/栈预留；同工具链 C 基线对照和 Debug 数据见[本次记录](records/2026-10-04-cpp-refactor.md)。

构建和调试入口以现有 CMake/VS Code 为准；不再维护 Keil 构建。模拟输入不能替代新版实物回归，旧的 2026-09-18 记录保留当时事实。六轴 Yaw 仍为相对偏航，长时间断链后的缺包重建边界不因封装而改变。

## 当前实现相对早期方案的变化

| 早期方案 | 当前实现与原因 |
|---|---|
| 单向发送、只统计缺包 | 增加 ACK 与有限超时重传，对应题目重发要求 |
| SPI /8，9 MHz | BSP 第一次访问前覆盖 /128，562.5 kHz，适配一般寄存器访问限制 |
| 引入 LibDriver basic 与 MiaoUI | 使用精简原始寄存器驱动和静态层级菜单，控制等待、依赖和资源；不启用 DMP |
| 依赖 CubeMX 初始 NVIC | BSP 运行时配置优先级，接收端补充 USART2 IRQ |
| 仅有初步内存/时序估算 | 内存已有链接结果，真实时序和硬件精度仍待测 |
