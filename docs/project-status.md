## 系统定位与已确认条件

发送端采集一个双轴摇杆、四个按键、两个拨码和 MPU6500 六轴原始数据，在 MCU 上解算姿态，通过透明无线串口发给接收端。两端 SSD1306 分别显示菜单和实时数据；双方 USART2 分别输出诊断文本和 PC 数据。

无线模块按用户说明作为远程串口使用，可按 HC 类透明模块理解。MCU 不处理无线配对或 AT 指令，当前协议采用双向遥测/ACK。IMU 先以传感器 XYZ 为机体坐标，保留可配置映射；实际安装方向和无线往返时间尚未测量。

## 构建证据与边界

上一次 GNU Arm 完整链接：发送端 Flash 34,224 B、RAM 6,928 B；接收端 Flash 18,724 B、RAM 5,328 B。RAM 含 512 B 堆预留和 2,048 B 栈预算；未测动态最坏栈。构建命令见[复测入口](quick-start.md)，具体场景与结果见[实施记录](records/2026-09-18-software-verification.md)。

Keil 工程已纳入源码，但尚未执行 Keil 编译器。模拟中的链路延迟来自测试设定，不能作为无线模块性能；六轴 Yaw 是相对偏航，不能当绝对航向。离线后重新同步序号，无法精确重建长时间断链期间所有缺包。

## 当前实现相对早期方案的变化

| 早期方案 | 当前实现与原因 |
|---|---|
| 单向发送、只统计缺包 | 增加 ACK 与有限超时重传，对应题目重发要求 |
| SPI /8，9 MHz | BSP 第一次访问前覆盖 /128，562.5 kHz，适配一般寄存器访问限制 |
| 引入 LibDriver basic 与 MiaoUI | 使用精简原始寄存器驱动和静态层级菜单，控制等待、依赖和资源；不启用 DMP |
| 依赖 CubeMX 初始 NVIC | BSP 运行时配置优先级，接收端补充 USART2 IRQ |
| 仅有初步内存/时序估算 | 内存已有链接结果，真实时序和硬件精度仍待测 |

后续改变实现时同步更新本页状态、相关主题文档和验证记录，保留旧记录的日期含义。
